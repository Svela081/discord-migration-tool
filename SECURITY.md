# Security and privacy

Do not publish Discord user tokens, bot tokens, passwords, browser profiles, archives, externally shared MEGA links or private Discord server/channel contents. Use the official Discord bot API for posting, and grant a bot only the permissions needed for its task.

The browser-based source downloader is not an official Discord API integration, and Discord prohibits automating ordinary user accounts. A second account does not remove that risk. Stop if the platform presents a verification challenge.

File paths in the archive index are validated before import. Pending bot posts retain a marker when the outcome is uncertain; do not delete a pending marker without checking the destination for duplication.

For vulnerability reports, contact the repository owner privately. Do not post credentials or identifiable information in a public issue.
